# Invitación XV de María Fernanda

Proyecto listo para publicarse gratuitamente con GitHub Pages.

## Estructura

- `index.html`: página principal.
- `css/styles.css`: diseño y estilos.
- `js/script.js`: animaciones, contador y funciones.
- `assets/images/`: fotografías de la invitación.
- `assets/audio/`: música de fondo.

## Publicar en GitHub Pages

1. Sube **todo el contenido de esta carpeta** al repositorio `mafer-xv`.
2. En GitHub entra a **Settings → Pages**.
3. En **Source**, elige **Deploy from a branch**.
4. Selecciona `main` y `/root`, y presiona **Save**.
5. La dirección será: `https://mafer15-code.github.io/mafer-xv/`

No cambies los nombres ni muevas los archivos después de generar el código QR.
